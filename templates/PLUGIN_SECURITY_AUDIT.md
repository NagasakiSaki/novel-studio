# Runtime security boundary

Local alpha; not a security certification or public release. Phase 1.2 evidence is frozen in the source repository. The CLI init global tool inventory does not establish actual per-model schemas or invocation rights. Only observed tool events support runtime conclusions.

Phase 1.2.2 separates author Canonical/Backups, Writer-Workspace and Editor-Workspace. Writer exposes read/create/edit tools; Editor exposes read and report creation, with Review-Reports as its active root and explicit external read grants for snapshots. Neither declares Shell, network, MCP or delegation. Generated session profiles explicitly deny protected source directories, peer workspace, metadata, plugin writes and optional private roots, as well as commands/URL/MCP. These files are session rules only when passed via --settings. The author launcher supplies them with the correct cwd and does not alter global security settings. The plugin install does not enforce this automatically.

Writer native edits and editor report writes are confined by the documented session configuration, not an OS sandbox. All-write read-only fallback remains available. Snapshots are immutable author-created versioned copies. The author utility separately implements dry-run, exact-plan acknowledgement, source/target hashes, no-link reads, pinned parent directories, backups, cooperative locking, atomic single-file publication and recovery journals. It cannot authenticate a human or stop arbitrary same-user writers/administrators; it is not a multi-file database transaction. 

No model relays, credentials collection, hidden uploads, telemetry, MCP server, hooks or background services. The author launcher only invokes the explicitly supplied official agy executable with a fixed argv and no shell. Model calls still follow host/provider data policies. Current real regression results, skipped tests and remaining platform/path-alias limitations belong to the source Phase 1.2.2 reports; development logs and synthetic projects are excluded from this package. No full OS isolation or cross-platform host certification is claimed.
