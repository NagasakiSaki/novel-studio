# Suggested project layout

Create a user project outside the plugin installation. This file is a layout guide, not an initializer and not a command to overwrite existing directories.

- 01_设定/ — style contract, characters, world and confirmed canon
- 02_大纲/ — planned story and chapter outlines
- 03_草稿箱/ — drafts and history snapshots
- 04_正文定稿/ — author-confirmed final prose; protected
- 05_追踪/ — sourced continuity state and derived views
- 06_审稿报告/ — authorized report files

The alpha agents return drafts and reports in chat. Automated safe writing, tracking migration, backup/restore and finalization have not been implemented.
