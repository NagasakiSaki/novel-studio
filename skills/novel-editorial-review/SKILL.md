# Editorial review adapter

Input: an author-prepared immutable Manuscript-Snapshot and relevant setting/outline/style copies. Output: evidence-based findings in chat or a new versioned report in the configured Editor-Workspace/Review-Reports only. No source edits, state updates or direct writer-workspace access.

Read ../../vendor/oh-story/skills/story-review/references/story-logic.md and narrative-focus.md from the same folder. For language issues also read expression.md and style-resolution.md there. Those four files form the selected reference closure. Do not load the upstream solo/full/lean workflow, platform rubrics, checkers or subagent dispatch.

The author's book contract and Novel Studio rules override upstream defaults. Never enforce em-dash blocking, mandatory whitelist files, commercial hooks or word-frequency quotas. Resolve style from the specified book, including numbered directories; do not assume upstream's unnumbered paths.

Report objective inconsistency, aesthetic advice and uncertainty separately. Each finding needs a source location, evidence and a practical effect. When context is absent, state the missing evidence. A quiet scene is not defective merely because events move slowly. Offer scoped repairs without making new facts canon.
