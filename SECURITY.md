# Security

Local writing and the bundled example run offline. Model tasks send only the selected context to the official host or provider after author action. Optional provider keys use Windows Credential Manager. Novel Studio does not operate a model relay or manuscript service.

Projects, drafts, reviews, and versions live in the author's selected folder. The product uses role workspaces, explicit host policies and author confirmation for publishing revisions to the formal manuscript. The host policy is not operating-system isolation.

For a vulnerability, use the private reporting form under the repository's Security tab. Include the affected version, observable behavior, and synthetic reproduction steps. Keep manuscripts, prompts, credentials and personal paths out of public issues.

See the [security constraints](docs/SECURITY_AND_COMPLIANCE.md), [privacy policy](docs/PRIVACY_POLICY.md), [threat model](docs/THREAT_MODEL.md) and [third-party notices](THIRD_PARTY_NOTICES.md).
