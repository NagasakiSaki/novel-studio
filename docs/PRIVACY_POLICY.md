> 当前状态：Phase 1.2.2（2026-11-04）。采用分离的 Writer/Editor 工作副本、作者快照交接和显式 CLI 会话 Deny。主笔仅写草稿/提案，责编仅写独立报告；Canonical/Backups 在活动根外并被拒绝。作者启动器不改全局设置；正式晋升默认 dry-run，须精确差异批准、哈希复核和备份。不是 OS 账户隔离，也不保证所有工具/路径别名。下面早期阶段结论仅作为历史记录；当前源码报告为 docs/PHASE1_2_2_FINAL_REPORT.md。

Phase 1.1：宿主验收仅使用新建合成工程，并通过用户已安装的官方 agy CLI 调用现有宿主模型连接。模型交互不是完全离线。原始宿主事件流保存在外部测试目录，仓库仅保存必要的合成文本与脱敏摘要。主 Agent 的目录级只读隔离尚未证实；本地安全读取器不能代替宿主权限。

日期：2026-11-04；适用于当前本地原型，未运营云端服务。

Novel Studio 不建立账号或默认云端小说存储，不提供模型账号、密钥和额度，不提供 API 中转。当前工具不发网络请求，不采集遥测、设备标识、正文、人物设定、世界观、审稿报告或密钥用于训练/分析。不存在 Novel Studio 内容接收服务器。

作品由用户保存在自己指定的本地路径。插件代码、上游参考及测试与作品分离；测试只用合成文本，不复制私人小说。工具输出由用户主动运行后显示在其终端；不要把含私人内容的输出直接粘贴到公开 issue。错误信息不应包含正文或密钥。

Antigravity 和其模型供应商是独立的数据处理方。用户在宿主中使用 AI 写作、审稿或选择文件作为上下文时，宿主可能按其设置向供应商发送内容；本插件的本地优先承诺不等于宿主或模型完全离线，也不能代替其隐私政策和服务条款。

当前版本没有网络功能开关，因为没有实现独立网络服务。未来若提出可选网络能力，必须先发布接收方、目的、数据、必要性和关闭方式，用户明确选择后才可使用。永久禁止的代理/账号绕过等能力不因同意而加入。

用户控制作品副本与删除。插件安装、升级、卸载不删除作品或覆盖自定义规则。当前无作品迁移或清理服务，不自动遍历作品目录寻找数据。

隐私问题可按 SECURITY.md 的本地报告要求准备不含私人内容的最小复现；公开安全联系渠道尚未设定，不虚构邮箱。正式公开发布前须按发行范围复核隐私文本。


## Phase 1.2 当前权限结论（2026-11-04）

CLI 1.5.0 的显式会话 deny 已取得实际工具拒绝事件；仅列草稿 allow 不会关闭工作区其他默认写权限。原角色继续聊天交付，不开放自动写入。新增 assets/permissions/read-only-session.json，必须通过 --settings 主动加载；安装不自动应用，不修改全局配置。宿主权限检查不是 OS 隔离，提示词、Git 与备份也不是。定稿、世界观、人物与重要追踪改动必须逐次明确人类批准。

只用合成数据测试；无私人小说、密钥或账号数据进入证据。无新增依赖、网络连接、代理/中转、Hooks 或后台服务。宿主 AI 仍按 Antigravity/模型供应商政策处理上下文；不声称整个流程离线。真实权限证据、失败和未测范围以源码仓库的 docs/PHASE1_2_PERMISSION_AUDIT.md 和 docs/PHASE1_2_FINAL_REPORT.md 为准；审计原始证据不随运行包分发。上文早期阶段待办是历史记录。
