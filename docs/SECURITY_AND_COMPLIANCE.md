## 永久禁止

- 反向代理、模型 API 中转、自建中转站、隐藏第三方转发；共享 API Key、账号池、额度转售/分配。
- 伪装来源、客户端、设备或用户身份；通过代理或非官方接口规避地区、订阅、资格、速率、额度、账号验证、验证码和安全检查。
- 收集、共享、转售他人的订阅资格；自动换号规避限制。
- Cookie 提取、未经授权读取软件凭据、调用账号服务、绕过系统授权。
- 隐藏后台网络、未告知上传小说/提示词/文件、隐蔽数据收集和未经授权遥测。
- 未经确认修改代理、证书、防火墙或 DNS；不透明常驻程序。
- 模型安全策略绕过机制及“永久解限/保证所有题材生成”等宣传。

以上不因可选、实验、隐藏入口、用户成本或 Stars 而放行，也不作为未来待办。发现上游含这些功能时，只能排除相关文件/依赖并证明闭包安全，不能复制后隐藏菜单。

## 模型边界

允许 Antigravity 官方模型/Agent、供应商公开 API/SDK/官方 CLI、明确授权的连接方式和用户自部署本地模型。自定义端点须有供应商或相关工具公开支持依据，清楚展示实际目标，不得用于隐藏来源或绕过限制。

默认不提供密钥、不代管账号、不销售额度，不要求额外购买 API 服务。Phase 1.2.5 的可选官方连接必须由作者主动配置、明确供应商/目的地/数据/关闭方式；不自动收集密钥、不写普通配置或日志，使用系统凭据存储，绝不上传到 Novel Studio 服务器。真实连接验收按负责人安排暂缓，不能由 SDK mock 或目录可见性替代。

本地脚本可离线运行；AI 写作由宿主按模型连接处理，可能发送提示词/选中内容给供应商。不能声称插件保证宿主不联网或覆盖其服务条款。

## Local-First

作品、设定、记录和报告留在用户指定设备工程。无默认云端存储、正文训练/分析收集、遥测、后台同步和上传。研究下载公开文档与运行期用户数据传输是两回事；研究工具不得带入用户正文或凭据。

确需未来网络服务：先说明用途、数据、接收方、必要性、拒绝和关闭方式并获得明确授权。禁用不影响基本本地文件能力。此授权不能豁免永久禁止项。

## 文件与权限

- 安装树只放插件代码、文档、原始上游材料；作品与自定义规则在独立工作区。
- 操作根目录显式指定并解析，防止 ..、绝对路径、符号链接、Windows junction/reparse point 逃逸。
- 不任意删文件，不自动覆盖正文。破坏性操作必须确认；重要操作先 dry-run/备份，支持可验证恢复。
- 项目锁、revision/hash 校验、同盘临时文件和原子替换；多文件崩溃一致性单独验证。
- 正式作品和重要资料的晋升/恢复须具备以上保障。可弃工作副本内的原生草稿/报告编辑由明确会话边界控制，不宣称其具备逐次事务、备份或完整 OS 隔离；未具备保障的正式区写入延期。
- 最小权限目标：责编禁源文编辑/Shell/MCP，独立报告输出为明确例外；Agent 声明和提示词不单独构成强制隔离。不使用未经验证的 hooks，不默认高权限命令。
- 更新和卸载不读取、迁移或删除用户作品；不覆盖用户自定义规则。

## 第三方准入

核验仓库身份、精确 SHA、版权/许可、维护状态、源代码、网络、文件、外部命令、依赖和更新来源。记录修改、依赖与测试。未知行为先隔离，不默认装。只读脚本仍须检查路径和动态导入；Markdown 里的安装/上传指令同样需要审查。

## 文学内容

支持服务商规则内的成熟文学、政治社会议题、创伤、暴力后果、道德困境、复杂亲密关系和人物灰度。不得把正常成熟文学等同于违规内容；拒绝时可提供合规叙事方案，不开发服务端安全绕过。

## 每项功能的九问

是否符合官方插件规范、服务商公开规则、适用法律；是否侵犯隐私、索取不必要权限、涉及代理中转、危及账号、暴露作品；是否有更安全更简单的实现。判断与未决事项必须进入审查记录。

## 发布要求

运行离线静态门禁并记录人工审查。必须核查代理、中转、密钥、外联、遥测、高权限 hooks、上传、删除覆盖、依赖来源和更新数据边界。[威胁模型](THREAT_MODEL.md)、[隐私说明](PRIVACY_POLICY.md)、本次审查与每个正式版本的版本化报告一并维护。

扫描只能覆盖已编码规则，不能证明法律合规、服务条款合规、所有恶意逻辑不存在或宿主隔离有效。正式发布前还需人工源代码审查、适用地区评估、官方 CLI 和宿主实测。

只用合成数据测试；无私人小说、密钥或账号数据进入证据。无新增依赖、网络连接、代理/中转、Hooks 或后台服务。宿主 AI 仍按 Antigravity/模型供应商政策处理上下文；不声称整个流程离线。真实权限证据、失败和未测范围以源码仓库的 docs/PHASE1_2_PERMISSION_AUDIT.md 和 docs/PHASE1_2_FINAL_REPORT.md 为准；审计原始证据不随运行包分发。上文早期阶段待办是历史记录。
