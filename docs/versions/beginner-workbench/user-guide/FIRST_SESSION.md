# Novel Studio 第一次使用

保留程序的完整文件夹，双击 `NovelStudio.exe` 打开工作台。

## 写第一份草稿

1. 在「作品」页点「新建作品」。输入书名，选择存放作品的文件夹，再核对界面给出的保存位置。
2. 点击「创建作品」，进入作品首页。点「写草稿」，再点「新建草稿」。
3. 在编辑区输入正文，点击「保存草稿」。下次在「作品」页打开该作品，再从草稿列表继续编辑。

已经有 Novel Studio 作品时，点「打开已有作品」，选择作品自身的文件夹。想先看看界面怎么区分草稿和审稿，点首页的「阅读草稿与审稿意见」，即可离线阅读内置示例《白榆镇回声》。

## 准备好后使用 AI

1. 在作品页点「首次 AI 协作」，分别配置主笔和责编。使用 Antigravity 可先在「设置 → 高级与安装 → 开发者诊断与安装」安装随包写作组件，再在模型配置中读取官方目录。使用官方 API 时，选择接收方和模型，保存凭据并确认对应角色的发送授权。
2. 写几句故事构思。已有设定也可以在「资料」页导入并批准。点「预览发送范围」，核对责编的模型、接收方、资料和费用提示，再决定是否发送。责编生成的大纲先保存为候选，由你查看并确认。
3. 确认大纲后，在作品页再次点「首次 AI 协作」。预览所选的一章和两位角色的接收方，再点「开始试写 1 章」。模型服务可能计费。
4. 完成后点「查看待确认章节」，阅读草稿和独立审稿。要把草稿收录为正式章节，先核对编号和差异，再明确批准。

## 保存和导出

文稿和审稿页的返回按钮会回到打开它们的入口。在「独立草稿与文件」中可以继续当前草稿，返回列表时未保存的输入仍保留在编辑器里。选择另一份文件时，程序会提醒你处理尚未保存的内容。

章节正文会标出草稿或正式稿。收录按钮只采用当前筛选范围内的章节，确认前仍可在编号和差异界面核对。资料库显示所选资料的版本、章节和本机来源。搜索结果用于查找内容，点击左侧具体资料后可打开更新、版本和恢复操作。

作品保存在新建时选择的文件夹。完成后可在「导出」页选择内容、顺序和格式，先预览再保存。需要保留整部作品的本地副本时，在作品操作的「更多操作」里选择「复制完整备份（ZIP）」。

## 换到新版继续写

需要额外保护的文件夹，可以在「设置 → 高级与安装 → 开发者诊断与安装 → 保护其他文件夹」添加。保存后，新作品会把这些目录列入主笔与责编的读取拒绝规则。已有作品继续使用各自保存的规则。保护配置独立保存，恢复默认界面时仍保留。

新版可与旧版同时安装。安装完成窗口会显示新快捷方式的名称。打开新版后，上次保存的作品会自动打开，也可以在「作品」页选择原来的作品文件夹。

若「设置 → 高级与安装 → 开发者诊断与安装」提示「作品绑定的组件不可用」，仍可以打开原稿、编辑和保存草稿。依赖旧组件的 Antigravity 对话要等原位置的组件恢复后再使用。升级时先保留旧安装，方便继续使用已经绑定的组件。
